## 🌐 How to Deploy to GitHub Pages

Deploying this portfolio to your GitHub account takes under 2 minutes:

### Option A: Via GitHub Desktop or Web
1. Create a new repository named `sourabh130.github.io` (or `portfolio`) on [GitHub](https://github.com/new).
2. Push or upload the contents of this folder (`e:\Potfolio`) to the repository.
3. In repository **Settings** &rarr; **Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` / `root`
   - Click **Save**.
4. Your website will be live at: **`https://sourabh130.github.io/`** (or `https://sourabh130.github.io/portfolio/`).

### Option B: Via Command Line (Git Bash / PowerShell)
```bash
# Navigate to the portfolio folder
cd "e:\Potfolio"

# Initialize git repository
git init

# Add all files (including all certificate documents and assets)
git add .

# Create initial commit
git commit -m "feat: complete developer portfolio and certificate showcase"

# Add your GitHub remote repository
git remote add origin https://github.com/sourabh130/portfolio.git

# Set main branch and push
git branch -M main
git push -u origin main
```
